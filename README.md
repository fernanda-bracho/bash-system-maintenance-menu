# Interactive Linux System Maintenance Menu

A robust Bash scripting project designed to streamline basic Linux system administration and health checks through an interactive command-line interface (CLI).

##  Features

* **Disk Usage Analysis:** Quick overview of mounted filesystems and available disk space (`df -h`).
* **Memory Monitoring:** Real-time inspection of available and used RAM (`free -h`).
* **System User Verification:** Automated check to validate user existence against system files (`/etc/passwd`).
* **Interactive Control Flow:** Built using continuous loops (`while`) and multi-branch selection (`case`) for continuous operation until explicit exit.

##  Prerequisites

* A Unix-like environment (Linux, macOS, or Windows Subsystem for Linux - WSL).
* Bash shell interpreter.
